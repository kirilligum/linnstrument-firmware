AdrenaLinn Software Versions

   The last software released for AdrenaLinn was version 1.5 (for the
   larger chip) and /1.6 (for the smaller chip).

   To check your software version of the larger of the two internal chips,
   connect power while holding the UP ARROW button. The latest version is
   1.5, shown in the display as "1-5".

   To check your software version of the smaller of the two internal
   chips, connect power while holding the DOWN ARROW button. The current
   version is 1.6, shown in the display as "1-6”.

   If your AdrenaLinn is running a version earlier than the final version
   1.5/1.6, you can upgrade to version 1.5/1.6 by purchasing and
   installing a pair of plug-in chips from our online store for $30.
