AdrenaLinn II Software Versions

   The last software released for AdrenaLinn II was version 2.1.2. The
   initial release was version 2.0.

   To check which software your AdrenaLinn II is running: While holding
   the UP ARROW button, connect power. The display will show either "212"
   (the latest version), "2-0" (version 2.0, the initial release) or "P20"
   (also the initial release).

   If you see a version other than the latest v2.1.2, you can upgrade to
   version 2.1.2 by purchasing a pair of plug-in chips contain the v212
   software from our online store for $30.
